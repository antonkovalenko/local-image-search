## The idea

I want a web-based tool that runs locally. Allows me to upload an image, select a rectangle of this image and start an image search to find the most similar images.
The best use cases - looking for pictures in a family archive of a family member.

I want results to be displayed not as single images but grouped by a folder they are located at. Every folder is represented by the topmost similar picture

I have an archive of images on my local drives. I want to index them once and then search this archive. I want to run this project locally: embedded, vector based indexes and everything else.

If there's a similar ready toolset I must consider it.
If clickhouse opensource could be used for this task – I need to consider this option.
